Tarkov Info Bot
Tarkov Info Bot is a Streamer.bot plugin that allows streamers and viewers to search the Escape From Tarkov Wiki directly from chat. It was created to make Tarkov information easier to access while keeping viewers engaged and interacting with the stream.

What Does It Do?
Tarkov Info Bot searches the Tarkov Wiki and returns the appropriate result directly in chat.

Command	Search
!info	Quests
!item	Items
!key	Keys and keycards
!ammo	Ammunition
!map	Maps
What about bosses? Yeah... I forgot about them. Boss searches will be added in v1.2.

Command Format
!command name
Full and partial searches are supported. Partial searches require at least 4 characters for proper results.

Example — Item Search
Command:
!item bitcoin
Returns:
Physical Bitcoin
https://escapefromtarkov.fandom.com/wiki/Physical_Bitcoin
________________________________________
Example — Partial Item Search
Command:
!item defib
Returns:
Portable defibrillator
https://escapefromtarkov.fandom.com/wiki/Portable_defibrillator
________________________________________
Example — Ammo Search
Command:
!ammo m855a1
Returns:
5.56x45mm M855A1
https://escapefromtarkov.fandom.com/wiki/5.56x45mm_M855A1

Why Would I Want It?
Tarkov has a lot of information, and viewers are going to have questions.
Instead of telling someone to leave the stream and search the Wiki, you can say:
"Check this out — type your search in chat."
Even when the streamer doesn't know the answer, Tarkov Info Bot makes that information accessible from chat. This helps keep the viewer on your page and creates another opportunity for interaction between the streamer and community.
The streamer can also use the commands for quick access to the Wiki.
Tarkov Info Bot operates through Streamer.bot using code written by novice/hobbyist developer GeneralGuess on Twitch.

How Do I Get It?
1.	Download the latest release from GitHub.
2.	Open Streamer.bot.
3.	Use Streamer.bot's Import function.
4.	Import Tarkov Info Bot.
5.	Start searching.
No separate installation is required.
